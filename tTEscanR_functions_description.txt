This file contains the usage table of each file included in tTEscanR

###
FILE: tTEscanRObject.R

DESCRIPTION:
This file contains the definition of the tTEscanR object that will be continuously used across the different functions in tTEscanR.
The tTEscanR object is a centralized data structure to store: (i) input data, (ii) metadata, (iii) results.

CONTENT:
- Create_tTEscanR_Object() - Visible

HELPER FUNCTIONS: tTE_HelperFunctions_tTEscanRObject.R
###

###
FILE: tTE_HelperFunctions_tTEscanRObject.R

DESCRIPTION:
This set of functions evaluate and update an existing tTEscanR object.
This approach ensures robustness.

CONTENT:
- DefineNewData() - Internal
- Update_tTEscanR_Object() - Visible
- CheckInputCombinations() - Internal
- IsIn_tTEscanR_Object() - Internal
###

###
FILE: tTEscanR_General

DESCRIPTION:
This file contain the function that runs the whole pipeline at once.
It requires a pair of mRNA and tRNA expression count matrices and performs the analysis
at the codon-anticodon and the amino acid demand and supply to obtain the theoretical translation efficiency (tTE) scores.

CONTENT:
- Run_tTEscanR_pipeline() - Visible
###

###
FILE: CodonUsage.R

DESCRIPTION:
This set of functions transforms mRNA and/or tRNA gene expression count matrices into
codon usage and/or anticodon usage matrices, respectively.

CONTENT:
- ComputeCodonUsage() - Visible
- ComputeAnticodonUsage() - Visible

HELPER FUNCTIONS: tTE_HelperFunctions_CodonUsage.R

###
FILE: CodonFreqPerGene.R

DESCRIPTION:
This function obtains a codon frequency per gene table.
The outcome table contains the counts of each codon present in each
protein-coding gene of a target organism. The function can be executed
in an exploratory (all genes) or a targeted (user-defined list of genes) way.

CONTENT:
- ObtainCodonFreqPerGene() - Visible

HELPER FUNCTIONS: tTE_HelperFunctions_CodonFreq.R

###
FILE: TheoreticalTranslationEfficiency.R

DESCRIPTION:
This set of functions take mRNA and tRNA data and correlates it in order to get an approximation of
the translation efficiency, here called theoretical translation efficiency (tTE).
The mRNA data can be represented as codon usage or amino acid (AA) demand, whereas
the tRNA data as anticodon usage or aa supply.

CONTENT:
- Compute_tTE() - Visible

HELPER FUNCTIONS: tTE_HelperFunctions_TranslationEfficiency.R
###

###
FILE: tTE_HelperFunctions_TranslationEfficiency.R

DESCRIPTION:
This set of functions compute independent metrics to complete the
theoretical translation efficiency (tTE) computation.

CONTENT:
- ComputeStatisticalSignificance() - Internal
- ComputeCorrelation() - Internal
- FilterMatrix() - Internal

MAIN FUNCTION: TheoreticalTranslationEfficiency.R

FILE: DifferentialExpressionAnalysis.R

DESCRIPTION:
This set of functions define a new module in the tTEscanR package.
The functions included perform or complement the differential expression analysis of different features.
DESeq2() is used to perform the differential expression analysis.

CONTENT:
- ComputeSizeCorrection() - Visible
- ExecuteDESeq2runner() - Visible

HELPER FUNCTIONS: tTE_HelperFunctions_DEA.R

###
FILE: PermutationTest.R

DESCRIPTION:
This set of functions performs a permutation analysis of a dataset with respect
to the reference codon frequency-per-gene matrix. Moreover, it computes the statistical
significance to be used for visualization purposes.

CONTENT:
- GetPermutationDist() - Visible
- ObtainSignificance() - Visible
###

###
FILE: tTE_HelperFunctions_GeneralInternal.R

DESCRIPTION:
This set of "check" functions are called internally by several functions in tTEscanR.
Their main objective is to evaluate different inputs in order to ensure that the downstream analysis can be executed.
This approach ensures robustness.
In several cases there is no returned output unless an error is reported.

CONTENT:
- CheckCodonFreqTable() - Internal
- CheckDataFrame() - Internal
- CheckGeneAnnotation() - Internal
- CheckCorrFactor() - Internal

DESCRIPTION:
This set of functions generate different plots for a better interpretation of the results.

Most of the data inputs are required to be previously transformed into long tables.

- tTE_ScoresPlot() - Visible
- tTE_CorrelationPlot() - Visible
- tTE_PermutationPlot() - Visible

HELPER FUNCTIONS: tTE_HelperFunctions_tTEscanRPlots.R
###

###
FILE: tTE_HelperFunctions_tTEscanRPlots.R

DESCRIPTION:
This set of functions complement the main functions that generate different plots for a better interpretation of the results.
The main objective is to check if the data is given in a proper format and if all the columns have been properly referenced.
With these functions we also control the different versions/layouts of each type of plot.

CONTENT:

- tTE_ProportionPlot() - Visible
